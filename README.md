## 🚀 Sobre o Projeto

O **TaskFlow** é uma aplicação de lista de tarefas (To-Do List) criada como um projeto prático para aprofundar conhecimentos no ecossistema do **React**. 

O principal objetivo foi dominar conceitos fundamentais da biblioteca, como componentização, gerenciamento de estados (`useState`), ciclos de vida/efeitos colaterais (`useEffect`) e a manipulação da API nativa do navegador para manter os dados salvos mesmo após fechar a aba.

### 🌟 Principais Funcionalidades
* **Persistência com LocalStorage:** Suas tarefas não somem! Tudo fica salvo de forma segura no próprio navegador do usuário.
* **Criação e Deleção Fluida:** Adicione e remova afazeres rapidamente com uma interface limpa.
* **Controle de Status:** Marque tarefas como concluídas com apenas um clique.
* **Design Responsivo:** Layout adaptável para uso confortável tanto no computador quanto no celular.

## 🛠️ Tecnologias Utilizadas

* **[React](https://react.dev/):** Biblioteca principal para a construção da interface modular.
* **JavaScript (ES6+):** Lógica da aplicação e manipulação de arrays/objetos.
* **HTML5 & CSS3:** Estruturação e estilização visual.
* **Web Storage API (LocalStorage):** Armazenamento local dos dados.

## ⚙️ Como Executar o Projeto

Caso queira rodar o projeto localmente em sua máquina para estudar o código ou fazer modificações, siga os passos abaixo:

### Pré-requisitos
Você vai precisar do [Git](https://git-scm.com/) e do [Node.js](https://nodejs.org/) instalados.

### Passo a Passo

```bash
# 1. Clone este repositório
$ git clone [https://github.com/gabrielfteixeira/todo.git](https://github.com/gabrielfteixeira/todo.git)

# 2. Acesse a pasta do projeto
$ cd todo

# 3. Instale as dependências
$ npm install

# 4. Inicie o servidor de desenvolvimento
$ npm run dev
# (ou 'npm start', dependendo de como o projeto foi inicializado)
```
